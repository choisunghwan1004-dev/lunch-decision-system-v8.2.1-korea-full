# V8.2 전국 법정동 실제 데이터

이 폴더의 전국 법정동 데이터는 **행정표준코드관리시스템(code.go.kr)**의 공식 `법정동코드 전체자료`를 기준으로 사용합니다.

현재 공식 조회 화면에서 현존/전체 법정동 데이터는 전국 단위로 제공되며, 최신 화면에는 20,560건이 표시됩니다.

V8.2는 데이터를 프로젝트에 수동 복사할 필요 없이 다음 명령으로 공식 서버에서 받아옵니다.

```bat
npm run setup:korea
```

실행 순서:

1. 공식 법정동 전체자료 ZIP 다운로드
2. TXT 자동 압축해제
3. UTF-8/CP949 자동 판별
4. 법정동 코드 파싱
5. `locations` 테이블에 대한민국 → 시도 → 시군구 → 읍면동 → 리 순서로 UPSERT
6. 관리자 화면에서 연쇄 Select로 즉시 사용

공식 출처:
- https://www.code.go.kr/stdcode/regCodeL.do
- https://www.code.go.kr/etc/codeFullDown.do

법정동 데이터는 행정구역 개편에 따라 변경될 수 있으므로 `npm run setup:korea`를 다시 실행하면 최신 데이터로 갱신할 수 있습니다.
